Users Management

Overview

Users are the people who have access to your DHS platform account. Every person who logs in to the system — whether they are an office administrator, a field technician, or the business owner — is represented as a user. Each user has a profile with their name, email, phone number, role, and timezone, and can be assigned to one or more crews.

From this section you can:

  • Add new users with a role, contact information, and a password.
  • Edit existing users to update their profile, change their role, or reassign them.
  • Disable users who should no longer have access to the platform (without deleting their data).
  • Enable previously disabled users to restore their access.
  • Send password reset emails so users can set a new password.
  • Search and filter users by name, email, or role.
  • Manage profile pictures by uploading or removing avatar images.

Important: Users are not archived or deleted. Instead, they are disabled when they should no longer have access. Disabling a user prevents them from logging in but preserves all their historical data (past jobs, appointments, timesheets, etc.). You can re-enable a disabled user at any time to restore their access.

Users List View

The Users List View is the main view for managing all your users. To access it, navigate to Menu > Users.

Tabs

At the top of the list, a segmented control lets you switch between two views:

Tab What It Shows
Active Users All users whose accounts are currently enabled. These users can log in and access the platform.
Disabled Users All users whose accounts have been disabled. These users cannot log in but their data is preserved.

Controls and Filters

Above the table you will find:

  • A Search bar — type a keyword to filter users by name or email.
  • A Role filter — a multi-select dropdown that lets you filter the list to show only users with specific roles (Admin, Support, Crew Member, Owner). You can select multiple roles at once.
  • A New User button — click to open the add user form.

Table Columns

Column What It Shows
User The user's avatar (or initials if no avatar is set) followed by their full name (first name + last name). This column is sortable. Click the user's name to open their profile in edit mode.
Email Address The user's email address. This column is sortable.
Role The user's assigned role displayed as a colored tag: Admin (green), Support (yellow), Crew Member (blue), or Owner (gray). This column is sortable.
Crew The name of the first crew the user belongs to. If the user belongs to multiple crews, a "+N" badge appears that you can hover over to see a popover listing all their crews. If the user is not in any crew, this column is empty.
Actions Action buttons for the user (see Row Actions below).

Row Actions (Active Users Tab)

Action Icon What It Does
Edit Pencil icon Opens the user's profile in edit mode where you can change all their details.
Disable User with X icon Opens a confirmation dialog to disable the user. If the user has active job assignments, this button is grayed out and disabled with the tooltip: "Cannot Disable User With Active Job Assignments." This button is hidden for your own account (you cannot disable yourself).

Row Actions (Disabled Users Tab)

Action Icon What It Does
Edit Pencil icon Opens the user's profile in edit mode.
Enable Undo/restore icon Opens a confirmation dialog to re-enable the user so they can log in again.

Sorting

The data grid supports sorting by the following columns:

Sort Option Description
First Name Sort users alphabetically by first name (A-Z or Z-A).
Email Sort users alphabetically by email address.
Role Sort users by their assigned role.
Created At Sort by when the user account was created.
Updated At Sort by when the user profile was last modified.

Pagination

The list uses server-side pagination with a default page size of 10 users per page. Pagination controls at the bottom of the table let you navigate between pages. When filters or search terms change, the page resets to page 1.

Empty State

If no users match your search or filters, the table shows: "No Users Found."

User Roles

Every user in the system is assigned a role that determines what they can see and do. The four roles are:

Role Tag Color Description
Owner Gray The account owner. This role is automatically assigned to the person who created the account and cannot be changed from the user management form. There is typically one owner per account. The role field is shown as read-only text when viewing an Owner's profile.
Admin Green Full administrative access to the platform. Admins can manage users, crews, settings, and all business operations. This is the highest role that can be assigned to other users.
Support Yellow Support staff role. Intended for office and dispatch personnel who manage scheduling, client communication, and day-to-day operations but may not need full admin access.
Crew Member Blue Standard field worker role. Intended for technicians, installers, and other crew members who primarily work on jobs in the field. This is the default role when creating a user via Quick Add.

Note: When creating a user from the Crew Quick Add modal (for example, while building a crew), only Admin and Crew Member are available as role options. The Support role is not offered in that context.

Adding a New User

To add a new user to your account:

Step 1: Click the New User button at the top of the Users List View. A panel will slide open from the right side with the title Add New User.

Step 2: Fill in the user's profile information.

Add User Form Fields

Field Required Description
Profile Picture No Upload a profile image for the user. Click Upload Image to select a file. Accepted formats: any image file. Maximum size: 2 MB. Recommended size: 500px x 500px for best results. If an image is uploaded, a Remove button appears to clear it.
First Name Yes The user's first name. Must be between 2 and 50 characters and can only contain letters and spaces.
Last Name Yes The user's last name. Same validation rules as First Name: 2-50 characters, letters and spaces only.
Email Address Yes The user's email address. Must be a valid email format (maximum 254 characters). The system checks for duplicates when you leave the field — if the email is already registered, you will see: "This email is already registered. Please use a different email address."
Phone Number Yes The user's phone number with a country selector. Defaults to the US country code. The system validates the phone format based on the selected country.
Role Yes The user's role in the platform. Select from: Admin, Support, or Crew Member. (The Owner role cannot be assigned here.)
Timezone Yes The user's timezone. Select from a full list of timezones. This affects how dates and times are displayed for this user.
Description No An optional text description. Maximum 500 characters. The placeholder reads "Description (optional)." Use this for notes about the user's specialty, certifications, or responsibilities.
Set Password Yes The initial password for the user's account. This password will be sent to the user's email. See password requirements below.
Confirm Password Yes Retype the password to confirm. Must match the password entered above. Only appears after you start typing a password.

Password Requirements

The password must meet all of the following criteria:

  • Minimum 10 characters long
  • Maximum 128 characters long
  • At least one uppercase letter (A-Z)
  • At least one lowercase letter (a-z)
  • At least one number (0-9)
  • At least one special character (!@#$%^&*()_+-=[]{}|;:'",./<>?/~`)

If the password does not meet these requirements, you will see the error: "Password must contain at least one uppercase letter, one lowercase letter, one number, and one special character."

Tip: You can use the Generate button (star icon next to the password field) to automatically create a strong password that meets all requirements. Use the Copy button (clipboard icon) to copy the generated password so you can share it with the user. You will see a confirmation: "Password copied."

A note below the password field reads: "The password will be sent to the recipient email."

Step 3: Click Add User at the bottom of the panel to create the user account.

On success, you will see the toast message: "User successfully created." The panel closes and the new user appears in the list.

If creation fails, you will see: "Failed to create user."

Editing a User

To edit an existing user, click the Edit (pencil icon) button on the user's row, or click the user's name in the table. A panel will slide open from the right side with the title Edit User.

The edit form shows the same fields as the create form (Profile Picture, First Name, Last Name, Email, Phone, Role, Timezone, Description), pre-filled with the user's current information. The Set Password and Confirm Password fields are not shown in edit mode — instead, a password reset section appears.

Password Reset (Edit Mode Only)

Below the main form fields, a section titled Reset Password appears with the description: "Send a password reset link to the user's email address." Click the Send Reset Email button to send the link. The button shows "Sending..." while processing.

Note: The password reset section is not shown when editing your own profile — it only appears when editing another user's profile.

Disable/Enable Button (Edit Mode Header)

In the top-right corner of the edit panel (next to the close button), there is a Disable User or Enable User button depending on the user's current status:

  • For active users: Shows Disable User with a user-X icon. Clicking it opens a black confirmation popover.
  • For disabled users: Shows Enable User with an undo icon. Clicking it opens a black confirmation popover.
  • For your own account: The button is hidden (you cannot disable yourself).

Saving Changes

After modifying the user's information, click Apply Changes at the bottom of the panel. This button is only enabled if you have actually changed something.

On success: "User successfully updated." On failure: "Failed to update user."

Click Cancel to close the panel without saving.

Disabling a User

Disabling a user prevents them from logging into the platform while preserving all their historical data. This is the recommended approach when someone leaves your team or should temporarily lose access.

There are two ways to disable a user:

From the Users List View

  1. Make sure you are on the Active Users tab.
  2. Click the Disable (user with X icon) button on the user's row.
  3. A confirmation dialog appears with the title Disable User and the message: "Are you sure you want to disable this user? This will prevent them from logging in and accessing the app."
  4. Click Disable User (red button) to confirm, or Cancel to go back.

From the Edit Panel

  1. Open the user's profile in edit mode.
  2. Click the Disable User button in the top-right corner of the panel.
  3. A black confirmation popover appears with the same message: "Are you sure you want to disable this user? This will prevent them from logging in and accessing the app."
  4. Click Disable User to confirm, or Cancel to dismiss.

On success: "User successfully disabled." The user moves from the Active Users tab to the Disabled Users tab.

Warning: You cannot disable a user who has active job assignments. If a user is currently assigned to active jobs (the isInUse flag is true), the disable button will be grayed out and disabled. The tooltip reads: "Cannot Disable User With Active Job Assignments." You must first remove the user from those active jobs before you can disable their account.

Note: You cannot disable your own account. The disable button is hidden when viewing your own profile.

Enabling a Disabled User

To restore access for a disabled user:

From the Users List View

  1. Switch to the Disabled Users tab.
  2. Click the Enable (undo icon) button on the user's row.
  3. A confirmation dialog appears with the title Enable User and the message: "Do you want to enable this user? They will restore app access."
  4. Click Enable User to confirm, or Cancel to go back.

From the Edit Panel

  1. Open the disabled user's profile in edit mode.
  2. Click the Enable User button in the top-right corner.
  3. A black confirmation popover appears with the message: "Are you sure you want to enable this user?"
  4. Click Enable User to confirm, or Cancel to dismiss. The button shows "Enabling User" while processing.

On success: "User successfully enabled." The user moves from the Disabled Users tab back to the Active Users tab and can immediately log in again.

Profile Picture Management

Each user can have a profile picture (avatar) that appears throughout the platform — in the users list, crew member lists, appointment assignments, and more.

Uploading a Profile Picture

  1. Open the user's profile in add or edit mode.
  2. Click Upload Image next to the avatar placeholder.
  3. Select an image file from your computer.
  4. The image is displayed as a preview in the form.

Requirements:

  • File type: Any image format (JPG, PNG, etc.)
  • Maximum size: 2 MB
  • Recommended dimensions: 500px x 500px for best results

If the file is too large, you will see: "File is too large. Maximum size is 2MB." If the file is not an image, you will see: "Invalid file type. Please select an image file."

Removing a Profile Picture

If the user already has a profile picture uploaded, a Remove button appears next to the image. Click it to clear the avatar. The user's display will revert to showing their initials (first letter of first name + first letter of last name) in a gray circle.

Quick Add User

You can create a user quickly from other sections of the platform (such as when adding members to a crew) using the Quick Add feature. The Quick Add modal is titled Quick Add New User and shows a simplified form with an informational note: "Quickly add a new user without leaving this page. You can complete all details later."

Quick Add Form Fields

Field Required Description
First Name Yes The user's first name.
Last Name Yes The user's last name.
Email Yes Must be unique. The system checks for duplicates.
Phone Yes Phone number with country selector (defaults to US).
Role Yes Defaults to Crew Member. When creating from a Crew context, only Admin and Crew Member are available.
Timezone Yes The user's timezone.

The Quick Add form does not include the description field, profile picture, or password — a password is automatically generated, and the user can set their own via email. The locale defaults to English.

On success, you will see the toast message: "User created using Quick Add" with a View User button. Clicking View User navigates to the Users List View with the new user's edit panel already open, so you can add more details if needed.

Searching and Filtering

Search

The search bar at the top of the Users List View lets you filter users by keyword. The search applies to user names and email addresses. As you type, the list updates automatically.

Filter by Role

The Role filter is a multi-select dropdown with four options:

  • Admin
  • Support
  • Crew Member
  • Owner

Select one or more roles to see only users with those roles. This is useful for quickly finding all your admins or all your field crew members.

When filters or search terms change, the pagination resets to page 1.

Cross-Platform Usage

Users appear throughout the entire DHS platform:

Crews

Users can be assigned as members of one or more crews. Within a crew, one user is designated as the Crew Lead. When viewing the Users List View, the Crew column shows which crews each user belongs to. Disabled users still appear in crew member lists but are marked as "(Disabled)" and cannot be set as crew lead.

Appointments

When scheduling appointments, crews (and their member users) are assigned to handle the work. The system uses crew availability settings to determine when team members are available for scheduling.

Jobs

Users are assigned to jobs through their crew membership. The isInUse flag on a user indicates whether they have active job assignments — this is what prevents a user from being disabled while they still have active work.

Timesheets

Each user's work hours are tracked through timesheets. The timesheet system records when users clock in and out of jobs.

Reports and Dashboard

User data feeds into various reports including performance metrics, feedback ratings, and activity summaries. Users can be filtered in reports to see individual or team performance.

Chat and Messages

Users can communicate through the platform's messaging system. Each user's name and avatar appear in conversations and notification lists.
