Scheduler & Calendar

The Scheduler (also called the Calendar) is the central visual tool for managing your team's day-to-day schedule. It displays both Jobs and Appointments on a shared timeline, color-coded by crew, so dispatchers and managers can see at a glance who is working where and when. You can view the schedule in four different layouts — Day, Week, Month, and List — and interact directly with events through clicking, dragging, and double-clicking.

The Scheduler is accessible from the main navigation bar by clicking Scheduler. A mini version of the Scheduler also appears as a widget on the Dashboard home page.

1. Scheduler Toolbar

The toolbar sits above the calendar area and adapts to your screen size. On large desktops (1680 px+) everything appears on a single row. On tablets (768–1680 px) it splits into two rows, and on mobile (<768 px) it uses three rows. Regardless of layout, the toolbar contains the same controls:

ControlDescription
Today button Jumps the calendar to today's date, regardless of which view you are in. In List view, it resets the date range to today only.
Previous / Next arrows Navigate backward or forward by one day (Day view), one week (Week view), or one month (Month and List views). The arrows are hidden in List view when a custom date range is selected.
Date Picker Click to open a calendar popup where you can jump to any specific date. In List view, you can select a custom date range (start and end dates).
Crew Filter A multi-select dropdown listing all crews. By default it shows All Crews. Select one or more crews to filter the events on the calendar to only those crews. When filtering in Day view, only the selected crew columns appear.
Override Availability toggle When turned on, the system no longer blocks actions on unavailable time slots. You can drag events into unavailable times and create events in the past. This is useful for making corrections or handling scheduling exceptions. Visible on tablet and desktop layouts.
View Selector (Day / Week / Month / List) A segmented control that switches between the four calendar views. Your last chosen view is remembered in the browser (localStorage) and restored the next time you open the Scheduler. When used on the Dashboard widget, the Month view button is hidden.
+ New Job button Opens the Create Job modal. Appears as a filled primary-color button. On the Dashboard widget this button is replaced with a "View Scheduler" link that opens the full-page Scheduler.
+ New Appointment button Opens the Create Appointment modal (the same 4-step wizard described in the Appointments section). Appears as an outlined primary-color button.

2. Calendar Views

The Scheduler offers four distinct views, each suited for different planning horizons. In all views, events are color-coded using the crew's assigned color, and each event shows an icon to distinguish Jobs (hammer icon) from Appointments (document icon).

2.1 Day View

The Day view shows a single day broken into hourly time slots, with one column per crew. This is the most detailed view and is ideal for dispatchers who need to coordinate crew assignments minute-by-minute.

  • Layout: A timeline grid where each row is an hourly time slot (60-minute intervals) and each column represents a crew. The crew name and color dot appear in the column header, aligned to the right.
  • Events: Displayed as colored bars spanning the appropriate time range. The bar shows the event name, a type icon (hammer for Jobs, document for Appointments), and a priority warning icon if the event is marked as high priority. Recurring jobs show a recurring icon.
  • Drag and Drop: You can drag a Job event to a new time slot within the same crew column. Dragging a job to a different crew's column is blocked with an error message: "Cannot drop event in a different crew column." When you start dragging, unavailable time slots are highlighted in gray (#E3E4E8) and a floating legend appears in the bottom-right corner showing what "Unavailable" and "Available" colors mean.
  • Creating Events: Double-click on any empty time slot to create a new event. A modal appears asking whether you want to create a New Job or a New Appointment. The clicked date, time, and crew are pre-filled in the creation form.
  • Past Time Slots: Time slots in the past are dimmed (reduced opacity, gray background). You cannot create events or drag events into past time slots unless the Override Availability toggle is on.

2.2 Week View

The Week view shows seven days (Sunday through Saturday) with hourly time slots across the horizontal axis. This is a custom-built component (not the default Syncfusion week view) that provides enhanced functionality.

  • Layout: A table where each row is a day of the week. The left column shows the day name (e.g., "Monday") and abbreviated date (e.g., "Jan 5"). The horizontal axis shows 24 hourly columns from 12:00 AM to 11:00 PM. The header row is sticky so it remains visible as you scroll.
  • Events: Displayed as colored bars positioned horizontally according to their start and end times. Events are stacked vertically within each day row if multiple events overlap. Each event shows a type icon, the event name, a priority icon (if applicable), and the time range. Multi-day events show continuation indicators (<< on the left, >> on the right).
  • Drag and Drop: You can drag Job events to different days and times. When dragging, unavailable time slots and entire unavailable days are highlighted in gray. The system validates availability using the same rules as the Reschedule Job modal, checking crew and client unavailable dates. Dropping on an unavailable slot shows the error: "Cannot schedule during unavailable times." Dropping on a past date shows a specific past-date error message.
  • Creating Events: Double-click on any time slot to open the Event Type Selection modal. The clicked date and time are pre-filled.
  • Scrolling: The entire week grid scrolls horizontally and vertically. When an event is opened via a URL deep link, the view auto-scrolls to center the event on screen.

2.3 Month View

The Month view shows a traditional calendar grid for the entire month. It provides a high-level overview of the schedule, useful for planning weeks ahead.

  • Layout: A standard calendar grid with abbreviated weekday headers (Mon, Tue, etc.) and cells for each day. The header cells display shortened three-letter day names.
  • Events: Displayed as compact colored bars inside each day cell. Each bar shows a type icon (hammer or document), the event name, and a priority or recurring icon. Multi-day events show date ranges (e.g., "Jan 5–7"). When there are more events than can fit in a cell, a blue "+X more" link appears at the bottom of the cell.
  • "+X more" Modal: Clicking the "+X more" link opens a modal titled with the full date (e.g., "Monday, January 5, 2026") that lists all events for that day. Each event in the modal shows its type (Job or Appointment), name, crew color and name, and time range. Clicking an event navigates to its detail page.
  • Drag and Drop: You can drag a Job from one day cell to another. When you start dragging, unavailable days are highlighted in gray. Unlike the Day and Week views, dropping a job in Month view opens the Reschedule Job Modal instead of immediately updating the schedule. This modal lets you choose the exact start and end times for the new date, ensuring accurate time-slot selection.
  • Creating Events: Double-click on any day cell to open the Event Type Selection modal. The clicked date is pre-filled.

2.4 List View

The List view (sometimes called Agenda view) displays events as a chronological list, grouped by date. It is best for reviewing a sequence of upcoming events without the spatial layout of a calendar.

  • Layout: Events are grouped by date, with each group showing the abbreviated day and date (e.g., "Mon 5") on the left. Horizontal separators divide date groups. Within each group, events are listed in chronological order.
  • Event Rows: Each row is 56 px tall and contains three columns:
    • Date column (100 px): Shows the day abbreviation and date number (only for the first event in each date group).
    • Time column (280–320 px): Shows the time range (e.g., "2:00 PM – 4:30 PM"). For all-day events it shows "All Day." For multi-day events it shows the full date range with time.
    • Event details: Shows the event name with a left-colored border matching the crew color, a type icon (hammer for Jobs, document for Appointments), and a priority alert icon if applicable.
  • Date Range Selection: In List view, the date picker in the toolbar changes to support custom date ranges. You can select a start and end date to view events across any span of time. When you switch to List view, it inherits the date range from your previous view (e.g., if you were viewing a specific week, the List shows that week's events).
  • Empty State: When there are no events in the selected date range, a centered message reads "No jobs scheduled in this date range" with a calendar icon.
  • No Drag and Drop: The List view is read-only for event positioning. You cannot drag events to reschedule them. Clicking an event opens its popover.

3. Event Popovers

When you click on any event in the calendar (in any view), a popover appears next to the clicked element showing quick-glance details about the job or appointment. There are two types of popovers: one for Jobs and one for Appointments.

3.1 Job Popover

The Job popover appears when you click on a Job event. It contains:

  • Title bar: The job name, with a recurring badge icon if the job is part of a recurring series.
  • Map Preview: An image preview of the job location. The system tries to display the property's custom photo first; if unavailable, it falls back to Google Street View, then Google Map View, then a placeholder icon. You can toggle between Street View and Map View using tabs above the image.
  • Address: The full address of the property, with a map icon button that navigates to the Map page filtered to this job.
  • Details grid:
    • Date: The scheduled date. Multi-day jobs show a date range (e.g., "Jan 5 – 7, 2026").
    • Time: The start and end times (e.g., "2:00 PM – 4:30 PM").
    • Client: The client company name, with clickable phone number and email below.
    • Crew: The crew name with a colored dot.
    • Crew Lead: The name of the crew lead, with their avatar photo if available.
  • Action buttons: "Cancel" (closes the popover) and "Job Details" (navigates to the Job's detail page).

3.2 Appointment Popover

The Appointment popover is similar to the Job popover but tailored for appointments. It contains:

  • Title bar: The appointment name (or "Untitled Appointment" if no name was set).
  • Map Preview: Same location preview as the Job popover, with Street View / Map View toggle.
  • Address: The full property address with map navigation button.
  • Details grid: Date, Time, Client (with phone and email), Crew (with color dot), and Crew Lead.
  • Action buttons: "Cancel" and "Appointment Details" (navigates to the Appointment's detail page).

4. Creating Events from the Scheduler

There are three ways to create new events directly from the Scheduler:

4.1 Using the Toolbar Buttons

  1. Click the + New Job button to open the Create Job modal, or click + New Appointment to open the 4-step Appointment wizard.
  2. These modals open without any pre-filled date/time information — you select the schedule manually in the form.

4.2 Double-Clicking a Time Slot or Day Cell

  1. Double-click on an empty time slot (Day or Week view) or an empty area of a day cell (Month view).
  2. An Event Type Selection modal appears with two large buttons: "New Job" (with a hammer icon) and "New Appointment" (with a document icon). Each button includes a brief description ("Create a scheduled job" or "Create a scheduled appointment").
  3. Click your choice. The corresponding creation modal opens with the date and time pre-filled based on where you double-clicked.
  4. In Day view, the crew is also pre-selected based on which crew column you clicked.
Note: You cannot create events in the past. Double-clicking on a past time slot is ignored. If you need to create a historical event, enable the Override Availability toggle first.

4.3 Pre-filled Values from Scheduler Clicks

When you create a new event by double-clicking the Scheduler, the following values are pre-filled in the creation form:

FieldPre-filled Value
DateThe date of the clicked cell
TimeThe time of the clicked time slot (Day and Week views only)
CrewThe crew of the clicked column (Day view only)

5. Drag-and-Drop Rescheduling

One of the Scheduler's most powerful features is the ability to reschedule Jobs by dragging them to new dates or times. This works across Day, Week, and Month views (not in List view).

5.1 How It Works

  1. Click and hold on a Job event bar until the cursor changes to a grabbing hand.
  2. Drag the event to the desired new date and/or time.
  3. As you drag, the system highlights unavailable time slots in gray (#E3E4E8). A floating Legend panel appears in the bottom-right corner explaining the color coding.
  4. Release the mouse to drop the event in its new position.

5.2 View-Specific Behavior

ViewDrag Behavior
Day Drag within the same crew column to change the time. Dragging to a different crew column is blocked. The job updates immediately on drop.
Week Drag to any day and time slot. Multi-day positioning supported. Drop snaps to nearest 30-minute interval. The job updates immediately on drop.
Month Drag to a different day cell. On drop, the Reschedule Job Modal opens so you can select the exact start and end times for the new date. The calendar reverts the visual change until you confirm in the modal.
List Drag and drop is not available in List view.

5.3 Validation Rules

The following rules are enforced during drag-and-drop rescheduling:

  • Past dates are blocked: You cannot drop a job on a date that is in the past. An error toast appears: "Cannot reschedule to a past date."
  • Unavailable time slots are blocked: The system checks crew availability, client availability, and service provider account-level unavailable dates. Dropping on an unavailable slot shows the error: "Cannot schedule during unavailable times."
  • Job duration is preserved: When you drop a job, the system preserves the original duration. For example, if a 3-hour job starting at 9 AM is dropped at 2 PM, it will span 2 PM – 5 PM.
  • Only Jobs can be dragged: Appointment events cannot be dragged to reschedule. If you try to drag an Appointment, the drag is canceled.
  • Jobs with restrictions cannot be dragged: Certain jobs (e.g., completed, archived, or invoiced jobs) cannot be rescheduled. Attempting to drag them shows an appropriate error message.
  • Day view: same crew only: In Day view, you cannot move a job between crew columns.

5.4 The Reschedule Job Modal (Month View)

When you drag a Job to a new date in Month view, the Reschedule Job Modal opens. This modal allows you to:

  • See the new date the job will be moved to.
  • Select the Start Time from available time slots.
  • Select the End Time from available time slots after the start time.
  • The modal only shows time slots that are actually available based on crew, client, and account unavailable dates.
  • Click Reschedule to confirm or Cancel to revert.

6. Availability & Unavailable Dates

The Scheduler integrates with the Availability system to visually indicate when crews and clients are unavailable.

6.1 How Availability Is Calculated

The system combines unavailable dates from three sources:

  1. Service Provider (account level): Company-wide days off, holidays, or closed periods set in Settings > Availability.
  2. Crew level: Each crew can have its own unavailable dates set on the Crew detail page.
  3. Client level: Clients may have unavailable periods set on their profiles.

All three sources are merged and deduplicated. If a time slot is unavailable in any source, it is treated as unavailable in the Scheduler. The system fetches unavailable dates for all visible crews and clients in a single API call, extending the date range by 7 days before and after the visible range to capture unavailable periods that extend beyond the visible window.

6.2 Visual Indicators

IndicatorMeaning
Gray cells (#E3E4E8) Unavailable time slots or dates. These appear when you start dragging an event to show where it cannot be dropped.
Dimmed cells (reduced opacity) Past time slots. These have a light gray background and reduced opacity.
White cells Available time slots where events can be dropped.

6.3 The Availability Legend

When you begin dragging an event, a Legend panel appears in the bottom-right corner of the screen (or bottom-right of the widget when on the Dashboard). It shows two colored boxes:

  • Gray box: "Unavailable"
  • White box: "Available"

The legend disappears when you release the drag.

6.4 Override Availability

The Override Availability toggle in the toolbar disables availability checks. When enabled:

  • Past time slots are no longer dimmed or blocked.
  • Unavailable slots are not highlighted during drag-and-drop.
  • You can create events and drop events at any time, regardless of availability restrictions.
Use with caution: Overriding availability can lead to scheduling conflicts. Use this feature only for corrections or exceptional situations.

7. Deep Linking from Other Pages

Several pages in the DHS platform link directly to the Scheduler and automatically highlight or open a specific event:

SourceURL PatternBehavior
Job Detail Page > "View on Scheduler" /scheduler?jobId=<id> Switches to Week view, navigates to the job's scheduled week, scrolls to the job event, and opens the Job Popover.
Appointment Detail Page > "View on Scheduler" /scheduler?appointmentId=<id> Switches to Week view, navigates to the appointment's scheduled week, scrolls to the event, and opens the Appointment Popover.
Appointment More Actions menu /scheduler?appointmentId=<id> Same as above — switches to Week view and focuses the appointment.

When navigating via deep link, the Scheduler auto-scrolls to center the target event on screen and then opens the popover with a brief delay to allow the calendar to render.

9. Event Display Details

Events on the Scheduler carry visual cues that help you quickly identify their type, crew, priority, and recurrence status.

9.1 Color Coding

Every event is colored using its crew's assigned color. If no crew is assigned, the event defaults to black (#000000). This makes it easy to scan the calendar and identify which crew is handling each event.

9.2 Icons

IconMeaning
Hammer (white) The event is a Job.
Document/Newspaper (white) The event is an Appointment.
Warning triangle (white fill, crew-colored stroke) The event is marked as high priority.
Circular arrow (white fill, crew-colored stroke) The event is part of a recurring series (either a template or an instance).

9.3 Multi-Day Events

Events that span multiple calendar days are displayed differently depending on the view:

  • Day view: Only the portion of the event falling on the current day is shown.
  • Week view: The event bar spans across multiple day rows. Continuation indicators (<< and >>) appear at the edges to indicate the event continues from/to another day.
  • Month view: The date range is shown as text below the event name (e.g., "Jan 5–7" or "Jan 28 – Feb 3").
  • List view: The time column shows the full date range with time (e.g., "Jan 5 – 7, 2026 at 2:20 PM").

10. Internationalization (i18n)

The Scheduler supports English and Spanish. When the user's language is set to Spanish:

  • Day names appear in Spanish (Domingo, Lunes, Martes, etc.).
  • Month names and date formats follow Spanish locale conventions.
  • All toolbar labels, tooltips, and error messages are translated.
  • The Syncfusion calendar component is configured with Spanish locale data (CLDR) for proper date and number formatting.

The language is determined by the user's i18n settings and changes automatically without a page reload.
