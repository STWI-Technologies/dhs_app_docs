Timesheets Management

Overview

Timesheets are how you track working hours for your team. Each timesheet belongs to a specific user and a specific date, and contains one or more time entries that record what the person did and for how long. Time entries are categorized by type — whether the person was traveling to a job site (en route), performing work at a job site (job time), or working in the office (office time).

Timesheets follow an approval workflow: they start as a Draft, get Submitted by the user for review, and are then either Approved or Rejected by an administrator or owner. This process ensures that hours are reviewed and verified before they are finalized.

From this section you can:

  • Create new timesheets for any user and date.
  • Add time entries to track specific blocks of work, travel, or office time.
  • Link and unlink time entries between timesheets.
  • Submit timesheets for approval.
  • Approve or reject timesheets (admins and owners only).
  • Delete timesheets and time entries (with restrictions on approved timesheets).
  • View analytics with summary cards showing total hours, en route time, office time, and job time.
  • Search and filter by date range, user, and status.

Important: Once a timesheet is Approved, it becomes read-only. You cannot edit, delete, or unlink time entries from an approved timesheet. This protects finalized records from accidental modifications.

Timesheets List View

The Timesheets List View is the main view for managing all timesheets. To access it, navigate to Menu > Timesheets.

Summary Cards

At the top of the page, four summary cards show aggregated statistics for the current view. Each card shows a value and a percentage change compared to the previous week (with an up or down arrow indicator):

Card Icon What It Shows
Total Hours Timer The combined total of all hours across all displayed timesheets. Shows percentage change compared to the previous week.
Total En Route Hours Truck The total travel time (en route hours) across all displayed timesheets.
Total Office Time Building The total office hours across all displayed timesheets.
Total Job Time Wrench The total on-site job hours across all displayed timesheets.

Tip: The summary cards update based on your active filters. If you filter by a specific user or date range, the cards show the totals for that filtered view only.

Controls and Filters

Below the summary cards you will find:

  • A New Timesheet button — click to open the create timesheet form.
  • A Search bar — type a keyword to search across timesheets (with a slight delay for performance).
  • A Date Range filter — select a predefined range or custom date range. Defaults to "All Time."
  • A User filter (hidden for crew members) — a multi-select dropdown to filter timesheets by specific users. Shows up to 100 users.
  • A Status filter — a popover with checkboxes for Draft, Pending, Approved, and Rejected. Shows a badge with the count of selected filters. Includes a "Reset filter" button to clear all selections.

Note: Crew members can only see their own timesheets. The User filter is hidden for crew members since they cannot view other people's timesheets. Admins and Owners can see all timesheets across the account.

Table Columns

Column What It Shows
User The user's avatar and full name.
Timesheet Date The date the timesheet covers, formatted as short month, day, and year (for example, "Feb 19, 2026"). This column is sortable.
Office Time Total office hours for this timesheet, displayed in HH:MM format (for example, "02:30").
Job Time Total on-site job hours for this timesheet, displayed in HH:MM format.
En Route Time Total travel hours for this timesheet, displayed in HH:MM format.
Status The timesheet's current status as a colored tag. This column is sortable.
Actions Edit and Delete buttons (see Row Actions below).

Status Tags

Status Tag Color Meaning
Draft Purple/Indigo background The timesheet is being worked on and has not been submitted for review.
Pending Gray background The timesheet has been submitted and is waiting for an admin/owner to review it.
Approved Green background The timesheet has been reviewed and approved. It is now read-only.
Rejected Red background The timesheet has been reviewed and rejected. The user should make corrections and resubmit.

Row Actions

Action Icon What It Does
Edit Pencil icon Navigates to the timesheet's detail page where you can view and manage all time entries.
Delete Trash icon Deletes the timesheet. This button is disabled for approved timesheets — the tooltip reads: "This timesheet has been approved and cannot be deleted."

Pagination

The list uses server-side pagination with a default page size of 10 timesheets per page. Pagination controls at the bottom let you change pages and adjust the page size.

Empty State

If no timesheets match your search or filters, the table shows: "No Timesheets Found."

Creating a New Timesheet

To create a new timesheet:

Step 1: Click the New Timesheet button at the top of the Timesheets List View. A modal dialog opens.

Step 2: Fill in the timesheet details.

New Timesheet Form Fields

Field Required Description
Date Yes The date this timesheet covers. Click the field to open a date picker. You cannot select a future date — the maximum date is today. Error if empty: "Date is required."
User Yes The user this timesheet belongs to. Select from a dropdown of all users. Supports Quick Add to create new users inline. Error if empty: "User is required."

Note: Crew members can only create timesheets for themselves. The User dropdown is disabled for crew members with the helper text: "Crew members can only create their own timesheets."

Step 3: Click Save to create the timesheet. The button shows "Saving..." while processing.

On success: "Timesheet successfully created." On failure: "Failed to create timesheet."

After creation, you will be taken to the timesheet's detail page where you can start adding time entries.

Timesheet Detail Page

The detail page is where you manage a single timesheet and all its time entries. To access it, click the Edit button on any timesheet row, or navigate directly after creating a new timesheet.

Page Header

At the top of the detail page you will see:

  • A Back button (chevron icon) — navigates back to the Timesheets List View.
  • The timesheet description or the user's full name as the page title.
  • The user's avatar and name with their crew affiliation.
  • The status — displayed as a dropdown for admins/owners (who can change it directly) or as a read-only label for crew members.

Overview Section

A summary table shows key timesheet information:

Field What It Shows
Date Created The date the timesheet covers, formatted as short month, day, year.
Crew The crew name with its color indicator. Shows "No Crew" if the user is not in any crew.
User The user's avatar, name, and crew affiliation.

Time Entries Section

Below the overview, the time entries are organized into two tabs:

Tab What It Shows

Unlinked Entries Time entries that exist but are not linked to any timesheet. You can link them to this timesheet or to a different one. This tab is hidden when the timesheet is Approved.

Above the entries table you will find:

  • A Search bar to filter entries.
  • A Date Range filter to narrow entries by date.
  • An Activity filter to show only specific entry types (All Activity, En Route, Work Time, Office Time).
  • An Add Time button (plus icon) to create a new time entry.
  • An Import Time button (download icon) to import entries from jobs.

Adding a Time Entry

Time entries are the individual blocks of work that make up a timesheet. To add a time entry:

Step 1: On the timesheet detail page, click the Add Time button (plus icon). The Add Time modal opens.

Step 2: Fill in the entry details.

Add Time Entry Form Fields

Field Required Description
Date Yes The date this work was performed. Cannot be a future date. Error if empty: "Date is required."
Job Conditional The job associated with this entry. Required for En Route and Work Time entries. Not required for Office Time entries (since office work is not tied to a specific job). Select from a dropdown of all jobs. Supports Quick Add to create a new job inline. Error: "Job is required for this time type."
Time Type Yes Select the type of work being recorded. Three options displayed as tab-like buttons: En Route (traveling to a job), Work Time (working on a job site), or Office Time (working in the office).
From Yes The start time of the work period. Uses a time selector. If the date is today, you cannot select a future time. Error if empty: "From time is required." Error if future: "Cannot select future time."
To Yes The end time of the work period. Must be after the From time. Error if empty: "To time is required." Error if before From: "To time must be after from time." Error if future: "Cannot select future time."
Description Yes A description of what was done during this time period. Multi-line text area (4 rows). Placeholder: "Describe what have been done." Always required.

Step 3: Click Save to add the entry. The button shows "Saving..." while processing.

On success: "Time entry successfully created." On failure: "Failed to save time entry."

Editing a Time Entry

Click the Edit (pencil icon) on any time entry to open the same Add Time modal pre-filled with the entry's current data. Modify any field and click Save to update it.

On success: "Time entry successfully updated."

Note: You cannot edit time entries on an approved timesheet. The edit button is disabled for approved entries.

Linking and Unlinking Time Entries

Time entries can exist independently (unlinked) or be associated with a specific timesheet (linked). This flexibility allows you to create time entries first and organize them into timesheets later.

Linking an Unlinked Entry

  1. Go to the timesheet detail page and switch to the Unlinked Entries tab.
  2. Click the Link icon on the entry you want to add.
  3. A popover appears with two options:
    • Link — Immediately links the entry to the current timesheet.
    • Select Another — Opens a modal where you can choose an existing timesheet or create a new one to link the entry to.

On success: "Time entry successfully linked."

Link Entry Modal (Select Another)

When you click Select Another, a modal opens with two options:

Option What It Does
Existing Timesheet Search for and select an existing timesheet from a dropdown. Shows timesheets as "User Name - Date" format.
Create New Timesheet Create a new timesheet on the spot by selecting a date and user, then link the entry to it.

Unlinking a Linked Entry

  1. On the Linked Entries tab, click the Unlink icon on the entry.
  2. A confirmation dialog appears with the title Unlink Time Entry and a confirmation message.
  3. Click Unlink to confirm, or Cancel to go back.

On success: "Time entry successfully unlinked." The entry moves to the Unlinked Entries tab.

Warning: You cannot unlink entries from an approved timesheet. The unlink button is disabled for approved timesheets.

Timesheet Approval Workflow

Timesheets follow a status-based workflow that ensures hours are reviewed before they are finalized. The flow works as follows:

Status Flow

Draft → (Submit) → Pending → (Approve) → Approved

Pending → (Reject) → Rejected

Pending → (Withdraw) → Draft

Available Actions by Status and Role

Status Who Available Actions
Draft Timesheet owner Submit Timesheet — Submits for review (status changes to Pending).
Pending Timesheet owner Change to Draft — Withdraws the submission (status changes back to Draft).
Pending Admin or Owner Approve Timesheet (green button) — Approves the timesheet (status changes to Approved).
Reject Timesheet (red button) — Rejects the timesheet (status changes to Rejected).
Approved Everyone No actions available. The timesheet is finalized and read-only.
Rejected Timesheet owner The user should correct the timesheet and resubmit.

Note: Admins and Owners can also change the status directly using a status dropdown in the detail page header, without using the action buttons. Crew members see a read-only status label instead of the dropdown.

Confirmation Dialogs

All status changes require confirmation before they are applied:

Action Dialog Title Confirm Button Style
Submit "Submit Timesheet" Submit Info (blue)
Approve "Approve Timesheet" Approve Info (blue)
Reject "Reject Timesheet" Reject Danger (red)
Withdraw "Change to Draft" Change to Draft Info (blue)

Toast Messages for Status Changes

Action Success Message Error Message

Deleting Timesheets and Time Entries

Deleting a Timesheet

To delete a timesheet, click the Delete (trash icon) on the timesheet row in the list view. A confirmation dialog appears.

On success: "Timesheet successfully deleted." On failure: "Failed to delete timesheet."

Warning: You cannot delete a timesheet that has been Approved. The delete button is disabled and the tooltip reads: "This timesheet has been approved and cannot be deleted."

Deleting a Time Entry

You can delete time entries from the Unlinked Entries tab by clicking the Delete (trash icon). The confirmation dialog title depends on the context:

  • For unlinked entries: Title is "Permanently Delete Time Entry" with a message explaining the entry will be permanently removed.
  • For linked entries: Title is "Delete Time Entry" with a message explaining the entry will be removed from the timesheet.

On success: "Time entry successfully deleted." On failure: "Failed to delete time entry."

Import Time Entries

The Import Time feature (download icon button on the detail page) allows you to import time entries from jobs. When you click this button, a modal opens with the following fields:

Field Required Description
Date Range Yes The date range to import entries from. Defaults to the current week (Sunday through Saturday). Error: "Date range is required."
Job Yes Select one or more jobs to import entries from. Multi-select. At least one job is required. Error: "At least one job must be selected."
Time Entries Yes Checkboxes to select which types of entries to import: En Route, Work Time, Office Time. At least one type must be checked. Error: "At least one time entry type must be selected."

Note: This feature is currently marked as "Coming Soon" and may not be fully operational yet.

Cross-Platform Usage

Jobs

Time entries are tied to specific jobs through the Job field. When you select a job for a time entry (En Route or Work Time type), the entry becomes associated with that job's record. Job names appear in the time entry table's Job column.

Users and Crews

Each timesheet belongs to a specific user. The timesheet detail page shows the user's crew affiliation. When viewing crew-related timesheets, crew names appear with their assigned color indicators.

Reports

Timesheet data feeds into the Reports section, where you can view daily and monthly views of hours worked. Reports offer additional breakdowns by employee, date range, job, and client, and support PDF generation for printing or sharing.
